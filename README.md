# Digital Witness — individual edition

An Android recorder with live preview, segmented audio/video, configurable personal storage destinations and independently verifiable integrity proofs. Application ID: `com.fieldnotes.recorder`. Version: 0.3 (code 3), Android 8.0/API 26 or newer.

Start with [build and installation](docs/BUILD.md). [First use and storage](docs/USAGE.md) explains the setup. See [validation](docs/VALIDATION.md), [security and limits](docs/SECURITY.md), and [handoff contents](HANDOFF.md).

This archive contains source and build tooling. It includes no signing key, account credentials, recordings or Git history. The recipient supplies their own signing identity and storage configuration. No organizer account, participant roster or shared Google Cloud project is required. Optional manual cloud integrations require the user's own provider credentials.
