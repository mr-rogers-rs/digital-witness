# Independent distribution

Use [HANDOFF](../HANDOFF.md) to verify the received source and [BUILD](BUILD.md) to produce an independently signed release. Review file contents and archive metadata before redistribution. Do not include signing keys, private configurations, recordings or Git history. Preserve [LICENSE](../LICENSE), [NOTICE](../NOTICE) and upstream attribution. A source cleanup cannot guarantee that an implementation, protocol or required credits cannot be linked to another distribution.
